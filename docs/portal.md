# 用户门户与双端统计

管理员在「用户管理」创建用户、分配密钥，并通过「余额与限制」充值、设置共享并发及日／周消费上限。用户通过 `/portal` 登录，只能查看自己的密钥、调用、钱包和流水，也可以验证当前密码后修改密码。修改密码会使全部旧会话失效。

## 用户钱包

一个用户的全部密钥共享钱包和并发槽位，原有单密钥限制仍然生效。充值以 USD 记账；同一操作编号重复提交不会重复入账。管理员不能把已有密钥换绑给另一用户，历史归属保持不变。

日上限在北京时间每天零点重置，周上限在北京时间周一零点重置。日／周金额上限与并发上限为 0 时表示不限。普通用户余额必须大于 0 才能开始新请求，余额为零或负数时拒绝调用，充值后恢复；此规则不能关闭。升级保留余额及流水，所有普通用户立即适用。

限制在请求开始时检查，不预占未知的输出费用。已经开始的请求仍按最终费用结算，可能使余额变负或超过日／周上限；随后拒绝新请求。钱包消费从功能启用后的新请求开始累计，不追溯扣除历史调用。本地直连数据只进入统计，不扣普通用户余额。

## 接口

普通用户接口使用独立 HttpOnly 会话 Cookie，管理员接口仍要求管理员身份。

| 方法 | 路径 | 内容 |
| --- | --- | --- |
| POST | `/api/portal/password` | `{oldPassword,newPassword}`，至少 12 字节的新密码 |
| GET | `/api/portal/wallet` | 自己的钱包和最近 100 笔流水 |
| GET | `/api/admin/portal/wallet?userId=...` | 指定用户的钱包和流水 |
| POST | `/api/admin/portal/wallet/policy` | `{userId,policy:{dailyLimitUsd,weeklyLimitUsd,maxConcurrency}}` |
| POST | `/api/admin/portal/wallet/credit` | `{userId,operationId,amount,note}`；操作编号为 UUID，金额为正十进制字符串 |

## 双端统计

`/combined-usage` 按北京时间展示本地直连和服务器代理的日、周、月、年用量。可切换 token、费用和响应次数趋势，查看热力图，按来源和日期筛选明细，导出当前结果。缓存已经包含在输入 token 内，不再次加到 token 总量。

上游账号额度是两端共享的账号观测值，各账号分别展示；不把百分比相加。缺失计价的记录只计 token 和响应，不按零费用宣称已完整计价。同步设备显示最后同步时间，未加载统计时显示缺失状态而非零用量。

页面顶部的当前周额度卡片显示各 Codex 账号的已用／剩余比例、整周及剩余美元容量估算和重置时间。预测合并同一账号绑定设备的本地记录与代理记录，截取到额度观测时刻，独立于历史日期／来源筛选。服务器导入前保留的本地记录可以作为更早的采集起点；这不保证站外记录完整，结果仍是可能低估的 API 等价估算。周期已过期、缺少真实周窗口或样本不足时不显示预测金额。相同设备的记录按同步修订去重；不要把同一份日志作为多个设备重复上传。
# 用户自建密钥与计费倍率

普通用户可在用户中心创建密钥（`POST /api/portal/keys`，仅接受 `name`），服务端生成随机密钥并原子绑定当前用户，最多保留 20 个。不能指定其他用户、额度或权限；新密钥与已有密钥共用用户余额、日周消费限制和总并发，上游账号并发仍独立生效。

管理员在“用户管理 → 计费倍率”设置全局倍率及模型覆盖（`GET/POST /api/admin/portal/pricing`）。请求模型 ID 精确匹配，模型倍率覆盖全局倍率，不叠乘。支持 0.000001 至 1000，最多六位小数，最多 200 个模型覆盖。

每次请求准入时固定计费规则版本。用户扣费为原始 USD 成本乘有效倍率，按八位小数结算；修改倍率不追溯进行中或历史请求。原始成本与倍率保存在账本，用户调用记录显示实际扣费，管理端上游成本及双端统计保持原价。
# 删除与当前周限

管理员可在用户管理中删除用户。删除使登录身份和全部密钥失效，保留钱包、充值、扣费及历史用量归属；余额不自动退款或转移。重新创建同名用户是独立身份，不继承历史数据。

普通用户可在“我的密钥”中删除自己的密钥。密钥从可用配置移除，历史调用与费用仍属于原用户，已准入的请求继续完成结算。两处删除均要求页面确认。

双端统计的“当前周限”按每个 OpenAI 账号的上游实际周期起点统计至查询时刻，再汇总。缺少有效边界时提示刷新额度，不使用自然周或最近七天替代。额度进度展示剩余比例，过期观测不当作当前剩余额度。
