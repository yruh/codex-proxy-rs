# 双端用量与普通用户后台

本分支增加两项能力：管理员在原后台查看本地直连与代理的合并用量；普通用户登录后只能查看自己所属的密钥和代理用量。

## 权限边界

- 管理员继续使用原有管理身份、会话和接口。
- 普通用户使用独立身份和会话，不能通过普通用户会话调用任何管理接口。
- 用户由管理员创建、停用和重置密码，不提供开放注册。
- 密钥归属由管理员分配。普通用户查询必须从服务器会话推导身份，不接收客户端指定的用户身份作为授权依据。
- 请求详情、统计、密钥展示都必须校验归属；其他用户的记录和上游账号凭据不可见。

## 双端账本

- 本地直连用量单独存储，不能写入代理请求执行记录或客户端密钥扣费表。
- 同步设备由管理员登记并绑定上游账号，凭据独立、可撤销，只允许写入该设备的记录。
- 使用设备 ID 与本地记录 ID 作为唯一键；重试幂等，修订序号防止旧批次覆盖新记录。
- 仅同步统计字段，不同步提示词、回复正文、登录令牌或 SSH 私钥。
- 合并统计分别列出来源。缓存属于输入，推理 token 属于输出；不同来源与代理的性能样本不能直接混算。
- 明确识别的预热事件排除于推理用量；缺少证据时保留采集状态，不用相同 token 数猜测预热或重复。
- 同账号的额度百分比取最新观测而非相加。周容量预测必须显示同步覆盖与样本不足状态。

## 验收要求

- 普通用户 A 无法读取用户 B 的密钥、记录、详情或统计，也不能调用管理员接口。
- 停用用户和撤销同步设备后，已有会话或凭据不再有访问权限。
- 重复上传、乱序上传、离线补传不导致重复或回退。
- 跨日、跨周、不同账号的数据正确归属；本地上传不增加同学的密钥扣费。
- 在隔离数据库验证迁移、接口与前端之后才部署，线上部署前备份并保留原镜像。

当前文档是实现约定，不代表上述功能已经完成或上线。
