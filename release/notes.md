# v3.15.2

## 问题修复

- 修复手动更换 Docker 镜像或程序后，历史更新记录导致误显示“已更新／立即重启”、隐藏下载入口的问题
- 核对实际安装文件与回滚备份，正确区分运行版本、已安装版本和待重启状态，避免失效备份参与在线回滚

## 功能与体验

- 系统更新支持临时选择 Stable、RC、Beta、Alpha 通道检查更新；选择不会保存或自动安装，重新打开时按当前运行版本匹配通道，不允许降级
- 通道选择使用紧凑分段切换，首次加载和切换时显示关键信息骨架屏，减少弹窗跳动；下载与安装过程沿用更新日志展示

## 升级说明

- 从本定制分支 v3.13.1 升级新增 `0026_plugins.sql`；既有 0001～0025 迁移保持不变。
- 若旧版本已误显示“立即重启”且没有下载入口，请通过 Docker 拉取新镜像或手动替换完整发行包升级；新版本启动后会校准历史更新状态
- 旧格式更新记录无法验证备份完整性，升级后不再提供对应的在线回滚；备份文件仍保留，需要恢复时请使用已核实的完整发行包

## 定制分支

- 保留用户余额、计费倍率、双端用量、历史周额度、长上下文计费开关和子代理模型路由。
